# Pinned to exact versions that were installed and tested against while
# building this project (see the companion explanation document for why

# resolve to a version with a changed API).

# Groq's own SDK is NOT imported directly in this project (Groq access

groq==1.7.0

# The Model Context Protocol SDK — powers src/mcp_tools_server.py (the
# server) and is used internally by google-adk's McpToolset (the client).

# Synthetic data generation.

# Testing (tests/). Not strictly needed to RUN the app, but included so
